2. **Не переходить к следующему этапу без явного подтверждения** (`PROJECT.md` §7).
3. **Не имитировать** тесты, сборки и команды. Невыполнимое — сообщать прямо (§9.3).
4. **Не класть секреты** никуда: код, логи, коммиты, публичные файлы, ссылки.
5. **Не добавлять зависимости** без реальной необходимости (`PROJECT.md` §5 уже фиксирует стек).
6. **Не обещать** то, что не проверено. В частности: не обещать «надёжные push в России»,
   двустороннюю синхронизацию с календарём, silent push на iOS, manifest `shortcuts` на iPhone.
7. **Ветка фиксирована:** вся работа в `arena/01a0f5ef-family-hub`. Не переключаться,
   не создавать и не пушить другие ветки.
8. **Деплой и cron оживают только после merge в `main`** — это действие владельца (§9.3).
9. **ИИ не имеет доступа к приватному репо семейных данных** — push-логика пишется на
   фикстурах в `infra/notifications/` и переносится владельцем.
10. **Единый источник версии — `version.json`.** Все дубли обязаны совпадать; CI падает
    при рассинхроне.

| ID | Вопрос | Когда проверяем | Как |
|---|---|---|---|
| Q1 | Работает ли GitHub App Device Flow из браузера (CORS на `/login/device/code` и `/login/oauth/access_token`)? | ЭТАП 2, спайк ~30 мин | Зарегистрировать тестовый GitHub App, включить device flow, выполнить обмен токена из реального браузера на GitHub Pages. | Q2 | Расходует ли `304 Not Modified` (ETag / If-None-Match) лимит GitHub API? | ЭТАП 2 | Замерить `X-RateLimit-Used` до и после серии условных запросов |

| Q4 | Доходит ли Web Push на iPhone 16 (PWA с Home Screen) после перезагрузки телефона? | ЭТАП 3 | Реальное устройство; сравнить классический SW-push и Declarative Web Push |
| Q5 | Сколько минут Actions реально тратит push-воркфлоу при активности семьи? | ЭТАП 3 → далее ежемесячно | Замерить длительность job и число запусков за неделю, экстраполировать на месяц; лимит 2000 мин/мес |

| Q7 | Работает ли Periodic Background Sync в Chrome на Honor (реальное поведение, а не поддержка API)? | ЭТАП 3, опционально | `registration.periodicSyncManager.register()` + наблюдение. **Эксперимент, не обязательство** |
