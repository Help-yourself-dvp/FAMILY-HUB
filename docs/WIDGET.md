# Виджет на рабочем столе: что возможно, а что нет

Ответ на вопрос владельца 13.10.2026: «Можем ли мы сделать виджет с минимальной информацией —
ближайшее событие и дело? Сможет ли он обновляться автоматически?»

## Коротко

| Вопрос | Ответ |
|---|---|
| Нарисует ли виджет само веб-приложение? | **Нет.** Виджет на рабочем столе Android — нативная функция платформы (рисуется кодом приложения на Kotlin, не веб-страницей). Это ограничение технологии PWA, а не наша недоработка. |
| Можно ли значок с числом на иконке приложения? | **Нет на Android.** Badging API (`setAppBadge`) поддерживают Chrome/Edge на компьютере и Safari на iPhone, а Chrome на Android его не поддерживает. Android сам ставит точку на иконку при уведомлении — этим управляет система. |
| Можно ли виджет с нашими данными вообще? | **Да** — силами программы-виджета на телефоне (MacroDroid, KWGT). Приложение публикует короткую сводку по секретной ссылке, виджет её показывает и сам обновляет по расписанию. |

## Что публикует приложение

Файл `feed/<секрет>.json` — рядом с календарной лентой, тот же секрет, та же ветка.
Ссылка видна в **Ещё → Настройки → Уведомления → Лента (подписка)** —
«Скопировать ссылку для виджета» (появляется, когда включён хотя бы один раздел).

Содержимое (пример):

```json
{
  "app": "family-hub",
  "format": "family-hub-widget",
  "updatedAt": "2026-10-13T06:00:00.000Z",
  "today": "2026-10-13",
  "sections": { "deadlines": true, "tasks": true },
  "deadline": { "title": "ТО автомобиля", "date": "2026-11-15", "days": 33, "human": "через 33 дня" },
  "task": { "title": "Забрать документы", "date": "2026-10-04", "days": -9, "human": "просрочено на 9 дней" },
  "openTasks": 5,
  "todayTasks": 1,
  "overdueTasks": 2,
  "within7": 1,
  "overdueDeadlines": 0,
  "line": "ТО автомобиля — через 33 дня · дел: 5 (просрочено 2)",
  "short": "ТО автомобиля — через 33 дня"
}
```

Для виджета достаточно поля `line` (готовая строка) или `short` (совсем коротко).
Правила те же, что у ленты: выключенный раздел в сводку не попадает, приватные сроки —
никогда. Файл обновляется тогда же, когда лента (запуск публикации после изменений,
а также кнопка «Обновить ленту сейчас»).

## Вариант 1: MacroDroid (то, чем владелец уже пользуется)

1. MacroDroid → **Макросы** → «+» (новый макрос).
2. **Триггер**: «Регулярный интервал» (Regular Interval) → 30 минут (или 1 час).
3. **Действие**: «HTTP-запрос» (HTTP Request) → метод **GET**, адрес — ссылка для виджета;
   «Сохранить ответ в переменную» → новая строковая переменная, например `fh`.
4. **Действие**: «JSON-разбор» (JSON Fetch / Parse JSON) → текст `{v=fh}`,
   путь `line` → переменная `fh_line` (если разбора в версии нет — можно сразу показать `{v=fh}`).
5. **Действие**: «Изменить кнопку виджета» (Widget Button Modify) → подпись =
   `{v=fh_line}` (в настройках виджета выбрать тип «Кнопка виджета», пользовательскую).
6. Долгое нажатие на рабочем столе → **Виджеты** → **MacroDroid** → перетащить
   пользовательский виджет и выбрать этот макрос.

Названия пунктов могут немного отличаться в зависимости от версии и языка MacroDroid —
ищите по смыслу.

## Вариант 2: KWGT (красивый текстовый виджет)

1. Установить **KWGT** (бесплатная версия подходит).
2. Новый виджет → добавить элемент «Текст» → в поле формулы:

   ```
   $wg("ССЫЛКА_ДЛЯ_ВИДЖЕТА", json, .line)$
   ```

3. Сохранить. Обновление — по интервалу обновления виджета в настройках KWGT
   (5–15 минут; чаще смысла нет: сама сводка обновляется вместе с лентой).

## Чего этим не сделать

- **Событий календаря в виджете не будет** — только сроки и дела из сводки.
- **Мгновенной реакции**: виджет перечитывает файл по своему расписанию (30 минут у
  MacroDroid, 5–15 минут у KWGT). Карточка в приложении всегда свежее.
- **Без сторонней программы** — никак: собственного виджета у веб-приложения быть не может.

## Альтернативы без сторонних программ

1. **Виджет календаря телефона.** Сроки и так приходят в календарь Honor (мост и
   подписка) — виджет календаря на рабочем столе показывает ближайшие события и
   обновляется сам. Это уже работает, настраивается в 3 касания.
2. **Уведомления приложения.** Напоминания приходят на телефон, если приложение
   установлено; уведомление видно в шторке — это ближайшее к виджету, что умеет
   веб-приложение.
