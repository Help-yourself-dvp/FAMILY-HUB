# «Мост» Family Hub → Google Календарь (инструкция владельцу)

## Зачем это

Лента Family Hub публикует файлы `.ics`, а Google умеет их «добавлять по URL». Но такой
календарь — **чужая подписка**: Google обновляет её раз в 12–24 часа, а на телефоне
(Android/Honor) события из подписки по URL часто **не скачиваются в память телефона вовсе**.
Проверено 06.10.2026: в веб-версии Google события ленты есть, на телефоне — нет; страница
`calendar.google.com/calendar/syncselect` с галочкой не помогла.

Событие, созданное **в настоящем Google-календаре** (кнопкой веб-формы в приложении), на
телефоне появляется сразу. Значит, нужен способ писать события ленты в настоящий
Google-календарь. Этим и занимается «мост» — небольшой скрипт **внутри вашего аккаунта Google**
(Google Apps Script). Ничего устанавливать на телефон не нужно, сторонних приложений нет.

Что он делает: каждые 15 минут скачивает файлы ленты из публичного репозитория
`Help-yourself-dvp/FAMILY-HUB` (ветка `feed`) и переносит события в отдельный календарь
**«Family Hub»** в вашем Google-аккаунте. Телефон синхронизирует этот календарь как обычный
Google-календарь — то есть так же быстро, как любые ваши события.

## Что понадобится

- Компьютер с браузером (телефон не подходит: редактор скриптов на телефоне неудобен).
- Вход в тот же Google-аккаунт, что и на телефоне.
- 10–15 минут один раз.

## Шаг 1. Создайте проект скрипта

1. Откройте **script.google.com** и войдите в свой Google-аккаунт.
2. Нажмите **«Новый проект»** (New project).
3. Слева сверху появится имя «Без названия» — нажмите и переименуйте, например
   в **Family Hub → Google**.

## Шаг 2. Вставьте код

1. Откройте файл с кодом в браузере:
   **https://github.com/Help-yourself-dvp/FAMILY-HUB/blob/arena/c7a7fb94-family-hub/scripts/google-bridge/Code.gs**
   (когда правки перенесут в `main`, эта же страница будет по адресу
   `.../blob/main/scripts/google-bridge/Code.gs`).
2. Нажмите кнопку **«Копировать»** (или выделите весь текст: Ctrl+A → Ctrl+C).
3. В редакторе Apps Script удалите строку `function myFunction() { ... }` и вставьте
   скопированный текст: Ctrl+A → Ctrl+V.
4. Нажмите значок «Сохранить» (Ctrl+S).

## Шаг 3. Запустите один раз и разрешите доступ

1. Вверху выберите функцию **`syncFamilyHub`** и нажмите **«Выполнить»** (Run).
2. Google покажет окно **«Требуется авторизация»** → **«Просмотреть разрешения»** →
   выберите свой аккаунт.
3. Появится предупреждение **«Google не проверял это приложение»** — это нормально: скрипт
   ваш собственный. Нажмите **«Дополнительно»** → **«Перейти на страницу Family Hub → Google
   (небезопасно)»** → **«Разрешить»**.
   Согласие нужно только на управление календарями (`CalendarApp`); доступ к почте, файлам,
   контактам скрипт **не** запрашивает.
4. Через несколько секунд в журнале (внизу) появится сводка вида
   `Family Hub → Google: создано 5, обновлено 0, без изменений 0, удалено 0, …`
5. Откройте **calendar.google.com**: слева, в разделе «Мои календари», должен появиться
   календарь **«Family Hub»** с событиями ленты.

## Шаг 4. Включите расписание (каждые 15 минут)

В левом меню редактора выберите **«Триггеры»** (значок будильника) и нажмите
**«Добавить триггер»**:

- Функция для запуска: **`syncFamilyHub`**;
- Источник события: **С учётом времени**;
- Тип триггера: **По минутам** → **каждые 15 минут**;
- Нажмите **«Сохранить»**.

Альтернатива: в списке функций выберите `installTrigger` и нажмите «Выполнить» — триггер
создастся сам (повторный запуск создаст второй триггер, лишний удалите в списке).

## Как проверить

- Добавьте новый срок в приложении Family Hub (как обычно) и нажмите в приложении
  «Обновить ленту сейчас».
- Через 1–2 минуты откройте таблицу запусков скрипта (журнал): в сводке должно вырасти
  «создано».
- В Google-календаре «Family Hub» появится новое событие; на телефоне — как обычное событие
  Google (обычно в течение нескольких минут).

## Что важно знать (границы)

- **Быстрота.** Событие попадает в Google-календарь в пределах ~15 минут после публикации
  ленты (плюс 1–2 минуты на саму публикацию). Это не «мгновенно», но и не сутки.
- **Будильники.** Google принимает напоминания не длиннее **4 недель**. Ступени сроков
  «за 90 дней», «за 30 дней» переносятся **без звонка** — само событие на месте; в сводке
  видно, сколько таких будильников пропущено.
- **Удаление.** Событие, удалённое в Family Hub, удалится и из Google-календаря «Family Hub».
- **Выключенный раздел.** Если в приложении выключить раздел ленты («Сроки» или «Дела с
  датой»), его файл публикуется пустым — события этого раздела уйдут и из Google.
- **Ошибка сети.** Если файл ленты не скачался, события этого файла не удаляются: лучше
  старое, чем пусто. В сводке будет «не прочитано: 1».
- **Названия событий** остаются теми же, что в ленте («Family Hub · …»).
- Скрипт работает **в вашем аккаунте**: семейные данные (кроме названий и дат событий ленты,
  которые и так лежат в публичных файлах) никуда не передаются. По правилу семьи
  диагностические сведения не содержат названий покупок/сроков: в журнал пишутся только
  счётчики.

## Если что-то не так

| Симптом | Что делать |
| --- | --- |
| Календаря «Family Hub» нет | Проверьте, что в журнале есть строка «Family Hub → Google: …». Если журнал пуст — запустите `syncFamilyHub` вручную (Шаг 3) |
| Сводка «лент 0» | Список файлов ленты не получен: лента ещё ни разу не публиковалась (включите раздел в приложении и нажмите «Обновить ленту сейчас») либо GitHub недоступен из вашей сети |
| Сводка «не прочитано: 1» | Один файл ленты не скачался — повторится на следующем запуске; старые события не удаляются |
| Событие не появилось через 15 минут | Откройте «Триггеры»: он включён? Затем вручную запустите `syncFamilyHub`. Если в Google-календаре событие есть, а на телефоне нет — проверьте, что календарь «Family Hub» включён в списке календарей приложения Google Календаря/телефона |
| Хочу всё убрать | Отключите (удалите) триггер, затем удалите проект на script.google.com и календарь «Family Hub» в Google-календаре — события уйдут, лента и приложение не затрагиваются |

## Для ИИ-ассистента (служебное)

- Файл: `scripts/google-bridge/Code.gs`. Настройки вверху файла: `FEED_OWNER`, `FEED_REPO`,
  `FEED_BRANCH`, `CALENDAR_NAME` (пустая строка — основной календарь), `FEED_URLS`
  (ручные ссылки; пустой список — авто-поиск файлов ветки `feed`).
- Проверки: `tests/google-bridge.test.ts` — скрипт запускается в песочнице с заглушками
  Google API на вымышленных лентах (сети нет).
- Мост **не** читает семейное хранилище (приватный репозиторий) и не требует токенов: только
  публичные файлы ленты.
- Не предлагать владельцу сторонние приложения календарей (решение 06.10.2026): ни из
  F-Droid, ни из магазинов. Apps Script — это встроенный сервис его аккаунта Google, а не
  приложение на телефоне.
- Владелец решение по мосту ещё не подтверждал: сначала его «да», потом настройка.
