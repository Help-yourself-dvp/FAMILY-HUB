# Как открыть Family Hub на телефоне — простая инструкция

Документ для владельца проекта. Никаких команд в терминале не потребуется: всё
делается мышкой на github.com и пальцем на телефоне.

Есть **два способа** открыть приложение. Коротко:

|                             | Способ А — «Посмотреть сейчас»       | Способ Б — «Постоянная ссылка»                    |
| --------------------------- | ------------------------------------ | ------------------------------------------------- |
| Что нужно сделать           | Ничего, просто открыть ссылку        | 6 кликов на github.com                            |
| Ссылка                      | временная (ниже)                     | `https://help-yourself-dvp.github.io/FAMILY-HUB/` |
| Сколько живёт               | пока открыта сессия разработки       | всегда, бесплатно                                 |
| Установка на экран телефона | ненадёжно (чужой домен)              | да, это основной вариант                          |
| Для чего                    | первый взгляд «что это вообще такое» | реальное использование и тест двух телефонов      |

Рекомендую: **посмотреть Способом А (2 минуты), затем сразу сделать Способ Б** —
он даёт постоянную ссылку, которую можно отправить второму члену семьи.

---

## Способ А. Посмотреть прямо сейчас (временная ссылка)

**Откройте в браузере телефона или компьютера:**

```
https://4173-i3av89682lvqaqj9c13fc.e2b.app/
```

Это «живой предпросмотр» — приложение, собранное в рабочей среде разработки.

Что важно понимать:

- Ссылка работает, **пока жива сессия разработки**. Закроете сессию — ссылка умрёт.
  Это не постоянный адрес приложения.
- Домен `e2b.app` — чужой и неизвестный вашему телефону. Поэтому кнопка
  «На экран Домой» на iPhone может не сработать или работать криво. Для Способа А
  это нормально: он нужен только чтобы посмотреть интерфейс.
- Если страница не открывается — значит сессия завершена. Тогда нужен Способ Б
  (или напишите мне, я подниму предпросмотр заново).
- Данные, которые вы там введёте, сохранятся только на этом устройстве и только
  до очистки сайта. Настоящая синхронизация проверяется на Способе Б.

## Способ Б. Постоянная бесплатная ссылка (GitHub Pages) — 6 кликов

GitHub Pages — это бесплатный хостинг от GitHub: он сам собирает приложение и
кладёт его по постоянному адресу. Карта не нужна, лимитов для нашего случая хватает
с огромным запасом. Один раз настроили — дальше всё обновляется автоматически.

Делать нужно **в этом порядке**: сначала включить Pages, потом влить код.

### Шаг 1. Включить Pages в репозитории (один раз, 3 клика)

1. Откройте: <https://github.com/Help-yourself-dvp/FAMILY-HUB/settings/pages>
   (это «Настройки» репозитория → раздел «Pages»; если ссылка не открылась —
   зайдите на <https://github.com/Help-yourself-dvp/FAMILY-HUB>, сверху вкладка
   **Settings**, слева в меню **Pages**).
2. Найдите блок **«Build and deployment»**, пункт **Source**.
3. В выпадающем списке выберите **«GitHub Actions»**.

> ⚠️ Не выбирайте «Deploy from a branch» — нам нужен именно «GitHub Actions».
> Больше на этой странице ничего менять не нужно.

### Шаг 2. Влить готовый код в главную ветку (3 клика)

Весь код ЭТАПА 1 лежит в ветке `arena/01a0f5ef-family-hub`. Приложения собираются
и публикуются только из главной ветки `main`, поэтому код нужно туда перенести.
Это стандартная операция, GitHub делает её сам:

1. Откройте: <https://github.com/Help-yourself-dvp/FAMILY-HUB/compare/main...arena/01a0f5ef-family-hub?expand=1>
2. Нажмите зелёную кнопку **«Create pull request»**, затем ещё раз **«Create pull request»**
   (ничего заполнять не нужно, текст уже есть).
3. Нажмите жёлтую кнопку **«Merge pull request»**, затем **«Confirm merge»**.

Если вместо ссылки удобнее по-старинке: вкладка **Pull requests** → **New pull
request** → base: `main`, compare: `arena/01a0f5ef-family-hub` → дальше те же две кнопки.

### Шаг 3. Подождать 2–4 минуты

Сразу после слияния GitHub запустит автоматическую сборку.

- Посмотреть прогресс: <https://github.com/Help-yourself-dvp/FAMILY-HUB/actions> —
  там будет процесс **«Deploy Pages»**. Жёлтый кружок = ещё работает,
  зелёная галочка = готово, красный крестик = ошибка.
- Если красный крестик — откройте его, скопируйте текст ошибки и пришлите мне.

### Шаг 4. Открыть приложение

**Постоянная ссылка (её можно отправлять семье):**

```
https://help-yourself-dvp.github.io/FAMILY-HUB/
```

### Если ссылка не открывается

| Что видите                                 | Причина                                          | Что делать                                                                                       |
| ------------------------------------------ | ------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| `404 There isn't a GitHub Pages site here` | Pages не включён или сборка ещё идёт             | Проверьте Шаг 1 и дождитесь зелёной галочки в Actions                                            |
| Пустая страница / белый экран              | сборка ещё не закончилась                        | Обновите через 1–2 минуты                                                                        |
| Старая версия после обновления             | кэш браузера                                     | Настройки → Настройки → «Версия и обновление» (внутри приложения), либо очистка сайта в браузере |
| Не открывается ни один адрес GitHub        | блокировки связи у оператора (в РФ такое бывает) | Напишите мне — это нужно зафиксировать как факт, он влияет на выбор хостинга                     |

## Шаг 5. Установить на два телефона (как обычное приложение)

**iPhone 16 (Safari):**

1. Откройте Safari (именно Safari, не Chrome и не Яндекс.Браузер — на iOS они
   не умеют установку на экран).
2. Откройте постоянную ссылку.
3. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх внизу экрана).
4. Пролистайте вниз → **«На экран Домой»** → «Добавить».
5. На главном экране появится иконка Family Hub. Запускайте как обычное приложение.

**Honor Magic 8 Pro (Android):**

1. Откройте страницу в Chrome.
2. Появится предложение «Установить приложение» (или: меню ⋮ → «Установить
   приложение» / «Добавить на главный экран»).
3. Подтвердите — иконка появится на рабочем столе.

Проверка, что установка настоящая: приложение открывается **без адресной строки**
браузера и работает в самолётном режиме (внутри будут те данные, что вы уже ввели).

## Шаг 6. Включить синхронизацию между телефонами

Без этого шага оба телефона живут каждый своей жизнью. Настройка делается один раз
на каждом телефоне, занимает ~5 минут, всё внутри приложения:

1. Откройте Family Hub → вкладка **«Настройки»**.
2. Раздел **«Подключение» → «Инструкция»** — там пошагово написано, как:
   - создать приватный репозиторий `family-hub-data` (ваше семейное хранилище данных),
   - создать ключ доступа (PAT) и вставить его в приложение.
3. Повторите на втором телефоне **с тем же репозиторием**, но ключ можно создать свой.
4. Добавьте покупку на одном телефоне → на втором она появится в течение нескольких
   секунд (при открытом приложении).

Дальше — тест из 4 пунктов (он же в `README.md`, раздел «Проверка на двух телефонах»):
синхронизация в обе стороны, удаление не «воскресает», очередь офлайн-изменений,
установка на обоих телефонах.
